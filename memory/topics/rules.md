# Rules for October
The Don't list and the mindset, from the All In Plan, October 2026.

- 2026-10-05: Don't refresh email and Upwork all day. Check twice a day
- 2026-10-05: Don't judge anything before Oct 31
- 2026-10-05: Don't spend on tools, courses or gear. Only pay for tools that directly help land or deliver client work
- 2026-10-05: Don't touch Jarvis or CryoPod before outreach is done

- 2026-10-05: Don't burn Connects on weak fits
- 2026-10-05: Don't cut sleep further. With no rest days, sleep is the only recovery
- 2026-10-05: Don't doomscroll other artists' highlight reels

- 2026-10-05: Hopeless usually means uncertainty dressed up as a prediction. "I don't know" is not "it won't"
- 2026-10-05: Long term: a game studio with successful games, several businesses, a life built on adventure. Titanium is the first brick

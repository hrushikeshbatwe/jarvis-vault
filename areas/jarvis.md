# Jarvis
- Wants to build a personalized Jarvis-style assistant: a dashboard that shows everything when opened, connected to his other apps (Google Health, Google Calendar, etc.) via MCP servers, used for whatever he wants to do
- Should run on both PC and mobile; PC side relies on Claude Code (CLI or MCP, either is fine), mobile side uses his OpenRouter API with a cheap model
- API cost budget: no more than $5/month
- Memory should be stored in Obsidian, and he plans to deploy the Obsidian vault somewhere other than his PC
- Wants a dashboard to look at every morning covering tasks, habits, work, Titanium and side projects
- Does not want to use TickTick; Jarvis should be his own system instead
- Wants the system to adapt to him and work with him, not against him
- Has an Alexa and wants a custom Alexa skill as an input to Jarvis
- Mobile app is important; wants it to use Nothing Phone (3) features (Glyph Matrix, Playground/Essential Apps, Essential Space); phone is on the Nothing OS 5 beta
- Everything should stay in sync across phone, PC and the rest of the system
- Doesn't want a goal-style system; wants one daily metric that says in one go whether the day is going badly
- Wants to track most things by voice, preferring free voice APIs; asked for quality-of-life features
